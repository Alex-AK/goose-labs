## Project overview

I replaced Spotlight with my own launcher. ⌘Space opens it like before. The difference is it's faster, it mostly just opens apps, I can change anything about it, and it adds tasks straight into [Pikos](https://pikos.app), the local-first notes, tasks, and calendar app I'm building.

Spotlight was bad at the one thing I used it for. It was slow and clunky, and it surfaced things I didn't want. Typing "arc" put the Family settings pane above Arc. Every so often the apps I use most dropped out of its index entirely. Changing any of that meant digging through System Settings, for a tool that does far more than I need. No more Spotlight BS.

The best part is recents. Open it with nothing typed and the five apps I opened last are right there. That one's huge.

![The launcher open with nothing typed, listing the five apps opened last](/launcher-recents.webp)

It's built on [Hammerspoon](https://www.hammerspoon.org), which lets you script macOS in Lua. I already had it running, so there was nothing new to install. It lives in my config repo, so a new laptop gets it too. Claude Code did most of the typing, and the first version came together in one morning.

### Notes

- I looked at Alfred and Raycast first. Alfred keeps its settings in a bundle the app writes, which I keep out of my config repo. Raycast is a lot more app than I wanted.
- There's no file search. Spotlight is still in the menu bar for that.

### Features

- **Recently opened**: The five apps I last opened, newest first, before I type anything.
- **Name decides the ranking**: A better name match always wins. How often I open an app only breaks ties.
- **Quick capture into Pikos**: Starting with `+` adds the text to my Pikos inbox through its CLI. If the add fails, the launcher says why.
- **VS Code workspaces**: Workspace files show up beside the apps, and Enter opens one in VS Code.
- **An exclude list**: Apps I never want, like Find My, never show up.
- **Picks up new things**: New apps and workspaces appear without a restart.
- **Keyboard first**: Arrow keys or Ctrl-N and Ctrl-P to move, Enter to open, Escape to close and go back to the app I was in.
- **Local**: No account and no sync. Nothing leaves the machine.

## Fully customizable

It's my code, so it does whatever I want. The whole ranking is one small function:

```js
// Name quality decides the band; launch count only orders apps within a band,
// so a heavily used app can never outrank a better name match.
function score(app, query) {
  let band;
  if (app.key === query) band = 4;
  else if (app.key.startsWith(query)) band = 3;
  else if (app.words.includes(" " + words(query)) || app.initials.startsWith(query)) band = 2;
  else if (app.key.includes(query)) band = 1;
  else return null;
  return band * 100000 + app.uses;
}
```

The Pikos capture and the workspaces are just other kinds of rows. Websites or a project's terminal session would work the same way.

## What I learned

- ⌘Space can't be a normal hotkey. macOS keeps it reserved even after you untick Spotlight's shortcut, so the launcher catches the key press with an event tap. That needs Accessibility permission.
- A fixed-size window doesn't jump. The window is sized for the full list and the page only draws what's in use, so the box never resizes while typing.
- Hide the last frame. Opening it used to flash the previous search, so now it fades in only once the page has drawn the empty state.
- Background tasks don't get your shell's PATH. The Pikos CLI needs a Node that Homebrew doesn't link, so the launcher sets PATH itself.
